# MSFS 2024 Linux – Experimental First Playable Milestone

Experimental source code and documentation milestone. No supported installer,
verified binary runtime release or official release tag is provided.

The Microsoft Store / Xbox PC edition of Microsoft Flight Simulator 2024 was
launched and successfully tested in a flight with a standard MSFS 2024 aircraft
on CachyOS Linux with an NVIDIA RTX 5090, as reported by the user. Cockpit,
landscape, instruments and user input worked in the observed test. The
project builds on Xodus and a modified Wine/Proton runtime with xgameruntime.
Credit and component licenses remain with their respective authors.

This observation applies to the preserved private working checkpoint. The
source revisions are recorded in SOURCE-VERSIONS.json. They must be validated
separately before they are called gameplay-tested.

- Fenix A320, Navigraph and BeyondATC have not been tested. No third-party
  add-on compatibility is claimed.
- Long-term stability and reproducible installation from a clean checkout are
  not yet validated. See INSTALLATION.md.
- Xbox cloud-save synchronization is not implemented. Local save writes were
  observed; restart/restore validation is pending.
- Marketplace, gamer pictures and other features remain incomplete.
- No game content, account credentials, private backups or proprietary runtime
  files are included. Users must own a legitimate game license.
- This is an independent community project without official Microsoft or Asobo
  affiliation or endorsement.

Official releases and version tags require OnlyCrayZ's explicit authorization.
